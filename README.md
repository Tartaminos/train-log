# train-log

Projeto base com Expo + TypeScript + expo-router para Android e iOS.

## Requisitos

- Node.js 18+
- npm 9+
- Expo Go (Android/iOS) ou emuladores configurados

## Instalação

```bash
npm install
```

## Executar em desenvolvimento

```bash
npm run start
```

## Executar no Android

```bash
npm run android
```

## Executar no iOS

```bash
npm run ios
```

## Verificação de tipos

```bash
npm run typecheck
```
